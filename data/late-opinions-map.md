first run, the Gemini drafts and the late DeepSeek run), with a verdict and the place it went in plan v2.

How to read it:

- `source` - file and line of the idea. Names are relative to the run folder (transliterated: `prognony-2/jev-papka-na-2-oct`
  in the owner's tree), except: `meta-plan-critic-full-text` is `work/plan-critique-meta/job/notes/step-007.md` (folder and file names transliterated)
  of the run (the full text behind `opinions-late/meta-plan-critic.md`); `gemini-drafts/...` is the Antigravity
  brain folder `40b89935-cda7-4502-b50c-06a22dca3bfc`; `first-run-opinions` is `opinions/` of the first run;
  `deepseek-run/...` is the run that arrived late from the DeepSeek seat.
- `verdict` - accepted (the plan carries it, or must carry it in the named stage), merged (the same idea is
  already in the plan from another source), partly (a part is taken, the rest is rejected for the reason
  given), rejected (with the reason).
- `where it went` - plan section (for example plan 0.7, plan 1.4), stage E1...E9, plugin, lesson step
  (B0...B13, K1...K4). Plan step names are given in Latin letters: B = the plan's business steps, K = the
  administrator steps.
- Plan section 1.4 says `opinions-2/` is a copy of `opinions/`. Checked on 2026-10-02 with `diff -rq`: the
  two folders are byte-identical (same 7 files), so every `opinions/` row covers `opinions-2` too (row L001 for
  the folder itself).
- Prices from these files are not copied into this map as facts: they go to `data/prices.json` only after the
  official page confirms them (E1, `data/facts-2026-10.md`).
